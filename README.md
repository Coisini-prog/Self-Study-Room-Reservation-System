# Self-Study-Room-Reservation-System
本系统是基于Spring Boot、Vue搭建的智能化自习室预约管理平台，服务于学生用户与后台管理员。系统融入多项AI智能创新能力。依托大模型意图识别与Function Calling技术，支持用户通过文本多轮对话完成自习室座位查询、预约、改签与取消，结合上下文记忆智能补全参数，实现自然语言一键预约。针对座位预约冲突痛点，系统创新设计候补排队与AI协商置换机制，结合用户信用分加权优先级自动转正名额，同时支持智能发起座位协商请求。此外，平台集成可视化座位状态展示、全自动超时释座、智能签到管控、数据可视化统计以及AI对话质量监控等功能，
