# 基于SpringBoot+Vue的智能自习室预约系统（含AI对话预约、候补协商功能）
本系统是基于Spring Boot、Vue搭建的智能化自习室预约管理平台，服务于学生用户与后台管理员。系统融入多项AI智能创新能力。依托大模型意图识别与Function Calling技术，支持用户通过文本多轮对话完成自习室座位查询、预约、改签与取消，结合上下文记忆智能补全参数，实现自然语言一键预约。针对座位预约冲突痛点，系统创新设计候补排队与AI协商置换机制，结合用户信用分加权优先级自动转正名额，同时支持智能发起座位协商请求。此外，平台集成可视化座位状态展示、全自动超时释座、智能签到管控、数据可视化统计以及AI对话质量监控等功能。

创新点：
✨ 创新点1：LLM智能对话预约
基于大模型实现自然语言预约，支持语音/文字多轮对话、自动解析预约条件、调用后端接口完成查座、预约、改签，告别传统手动点选，实现AI一键自习预约。
✨ 创新点2：座位冲突候补+AI智能协商
针对座位被占场景，支持信用加权候补排队、自动转正，同时提供AI换座协商功能，用户可自主发起换座请求，解决热门座位抢座难、资源闲置浪费问题。
✨ 创新点3：可视化平面图座位状态管理
采用彩色可视化平面图实时展示空闲/占用/暂离/故障座位状态，支持拖拽式座位后台配置，管理更直观、用户选座更高效。

一、技术栈
1.1 后端技术栈
- 核心框架：Spring Boot 2.7.18
- 持久层框架：MyBatis Plus
- 数据库：MySQL 8.0
- 安全认证：JWT
1.2 前端技术栈
- 核心框架：Vue 2.7.14
- UI 组件库：Element UI
- 路由管理：Vue Router
- 状态管理：Vuex
- HTTP 客户端：Axios
- 图表库：ECharts

- 个人资料维护：支持修改昵称、头像、联系方式
2.2 自习室查询与浏览模块

- 座位平面图：可视化楼层平面图展示座位分布，通过不同颜色区分座位状态（空闲-绿色、占用-红色、暂离-黄色、故障-灰色），支持点击座位查看详情
- 条件筛选：可按区域（A区/B区）、座位类型（单人桌/双人桌/静音舱）、设施（带电源/靠窗）筛选可用座位
- 时段选择：选择对应日期和时段后，平面图自动动态高亮该时段可用座位
- 详情查看：点击座位可查看环境描述、历史评分及用户评价内容
2.3 预约管理模块（含防冲突预约）
- 快速预约：选择座位、日期、起止时间（最小预约粒度30分钟），一键提交预约
  <img width="629" height="431" alt="预约座位" src="https://github.com/user-attachments/assets/bc25ef5a-4649-4674-ac03-f4772e71e666" />
- 防冲突预约：同一用户同一时段不可重复预约座位，规避预约冲突问题
- 续约功能：预约结束前，用户可在线延长使用时长，系统自动校验​​续期时段座位空闲状态
- 改签功能：支持更换为同类型空闲座位，原预约信息自动释放失效
- 取消预约：预约开始前15分钟可免费取消；距预约开始不足15分钟取消，将扣减用户信用分
- 预约日历：支持月视图/周视图展示个人全部预约记录，可导出预约数据
2.4 签到与签退模块（含地理围栏签到）
- 临时离开：用户可自主设置暂离状态，系统保留座位30分钟，超时未返回将自动释放座位并扣减信用分
- 签退释放：使用结束后手动点击签退，座位即时变更为空闲状态，对外开放预约
2.5 超时自动释放模块
- 未签到释放：预约开始后15分钟未完成签到，系统自动取消预约、释放座位，记录用户“无故缺席”违规
- 暂离超时释放：暂离时长超过30分钟未返回，系统自动释放对应座位
- 释放通知：座位被系统自动释放时，主动向用户推送提醒消息
- 释放回收：被释放的座位实时刷新至平面图，可供其他用户正常预约
2.6 评价留言模块
- 使用后评价：预约完成并签退后，用户可对自习室环境、安静程度、设施状况进行1-5星打分并留言评价
- 评价公开展示：用户评价公开展示在自习室详情页，供其他用户参考
- 留言回复：管理员可针对用户留言、评价进行回复，实现双向互动
- 我的评价：个人中心可查看本人发布的全部评价及管理员回复记录
2.7 个人中心模块

- 违规记录：可查看个人所有违规行为及对应发生时间

2.8 消息通知模块
- 签到提醒：预约开始前15分钟仍未签到，系统推送催促签到通知
- 违规警告：超时未签到、暂离超时、被投诉等场景，主动推送违规通知
- 反馈回复通知：管理员回复评价、申诉后，用户实时收到推送提醒
2.9 智能对话预约模块（AI创新）
  <img width="934" height="431" alt="ai助手" src="https://github.com/user-attachments/assets/40bcee75-9b7c-4ef7-8941-19d027d54b33" />
- 多轮对话入口：预约页面设置智能助手悬浮按钮及输入框，支持语音、文本两种输入方式
- 自然语言意图识别：AI自动识别用户输入指令，完成预约查询、预约创建、改签、取消等意图分类，自动填充日期、时间、区域、座位属性等槽位信息
- 函数调用（Function Calling）：LLM识别用户意图后，根据预定义JSON Schema，自动调用后端预约查询、座位筛选等API，获取实时数据后整理回复内容
- 上下文记忆与多轮追问：支持多轮连续对话，可关联上一轮对话上下文修正需求，无需用户重复输入基础条件
- 结果展示与确认：AI解析需求后，以自然语言展示匹配空位信息，用户确认后一键完成预约下单
- 模糊查询兜底：用户需求模糊或无匹配座位时，AI推送最接近的可选方案，并引导用户微调需求
- 对话历史记录：个人中心保存近期对话记录，支持会话重放、继续历史对话
2.10 冲突候补与协商模块（AI创新·用户侧）
  <img width="692" height="415" alt="候补队列" src="https://github.com/user-attachments/assets/11dca242-9399-4a9c-8100-5b3cbfae1a28" />
- 冲突提示：预约座位已被占用时，系统弹窗提示，支持选择加入候补队列
- 候补排队：用户确认候补后进入队列，系统根据候补顺序、信用分加权计算排队优先级
- 候补转正：目标座位释放且用户排名靠前时，自动转为正式预约并推送通知
- 协商提议：支持向已预约用户发送座位调换协商请求，LLM自动生成礼貌协商文案，对方同意后自动完成座位交换
